# Security Policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting feature for this repository:

1. Open the repository's **Security** tab.
2. Select **Advisories**.
3. Select **Report a vulnerability** and provide reproduction steps, affected
   versions, impact, and any suggested mitigation.

If GitHub does not show that option, email the repository owner at
`suttonwilliamd@gmail.com` rather than publishing exploit details.

Reports will be reviewed as maintainer availability permits. Please allow time
for investigation and remediation before public disclosure.
